🔥 What is Virtualization / Windowing?
👉 Definition:
Instead of rendering the entire list (e.g., 10,000 items), React renders only the visible items on the screen.
As you scroll:
Old items are removed
New items are added
💡 It’s like a moving window over your data → that’s why it’s called windowing.

🧠 Simple Analogy
Imagine:
You have 10,000 customers
But screen shows only 10 at a time
👉 Without virtualization:
React renders all 10,000 ❌ (slow)
👉 With virtualization:
React renders only ~10–20 items ✅ (fast)

🔹 Example Libraries
Common libraries used:
react-window
react-virtualized

virtualization (or windowing) is a performance optimization technique where only visible items are rendered instead 
of the entire dataset. For example, in a list of 10,000 items, only the items in the viewport are rendered,
 reducing DOM size and improving performance. Libraries like react-window help implement this efficiently.
